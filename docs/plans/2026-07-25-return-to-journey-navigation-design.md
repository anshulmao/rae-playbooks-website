# Return to journey navigation

Date: 2026-07-25

## Objective

Separate “Return to journey” from the primary “What’s next” actions and present
it visually as backward navigation rather than a competing CTA.

## Placement and treatment

- Place the control above the “What’s next” eyebrow.
- Label it “Return to journey” with a left arrow.
- Use a quiet text-link treatment with no filled background.
- Add a subtle horizontal hover movement and retain a visible keyboard focus
  state.

## CTA hierarchy

The main CTA row contains only:

1. Try Rae
2. Suggest a feature

- Confirm it remains connected to the existing screen-navigation behavior.
